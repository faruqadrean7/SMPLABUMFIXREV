Dokumen ini memuat daftar resmi seluruh akun uji coba (*demo accounts*) untuk keperluan demonstrasi kepada klien, komite sekolah, yayasan, dan calon pengguna. Seluruh akun di bawah ini telah terdaftar aktif pada database dan siap digunakan secara langsung.

## 1. Akun Siswa & Orang Tua (3 Tingkat Kelas × 4 Program Unggulan)

SISTLABUM mendukung 4 program unggulan resmi SMP Laboratorium UM:
1. **Reguler:** Kurikulum Merdeka Nasional, Projek Penguatan Profil Pelajar Pancasila (P5), dan pembinaan akademik/ekstrakurikuler.
2. **Tahfidz:** Program pembiasaan & setoran hafalan Al-Qur'an terpadu (Mutaba'ah harian & Tasmi').
3. **ICP (International Class Program / Cambridge):** Kurikulum bilingual Cambridge Checkpoint (Math, English, Science).
4. **Inklusi (PPI - Program Pembelajaran Individual):** Pendampingan khusus Guru Pembimbing Khusus (GPK) & pemenuhan milestone belajar adaptif.

Setiap akun siswa telah dipasangkan secara resmi dengan akun orang tua/wali murid masing-masing.

### 💻 Menjalankan Ulang Seeder di Server VPS
Seluruh data akun di atas dapat di-generate ulang kapan saja secara otomatis di VPS dengan menjalankan perintah:

```bash
cd apps/api
php artisan db:seed --class=ComprehensiveDemoSeeder
```
