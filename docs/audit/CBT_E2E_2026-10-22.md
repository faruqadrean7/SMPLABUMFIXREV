## 1. RINGKASAN EKSEKUTIF

Berdasarkan implementasi dan pengujian mendalam dua tahap pada branch `fix/cbt-hardening`, sistem CBT (Computer-Based Test) telah berhasil diperkuat (*hardened*) di sisi backend dan dibuktikan secara empiris mampu melayani seluruh skenario pengerjaan ujian siswa di frontend `apps/web`.

### Pencapaian Utama:
1. **Tahap 1 — Hardening Keamanan & Integritas Data**:
   - **Sanitasi Whitelist Penuh**: `ExamSessionService::getSessionQuestions` dirombak dari pendekatan *blacklist* menjadi **strict whitelist**. Seluruh atribut yang tidak terdaftar (seperti `secret_key`, `answer`, `explanation`, `rubric`, `internal_flag`) otomatis dibuang dari body soal dan opsi pilihan.
   - **Audit Anti-Kebocoran (No Answer Leak Scanner)**: Pengujian rekursif pada seluruh endpoint yang dapat diakses siswa sebelum ujian selesai membuktikan kunci sensitif (`is_correct`, `match_key`, `correct_answer`, `rubric`, `kunci_jawaban`, `answer_key`, `explanation`) **0% bocor** pada payload respons.
   - **Audit Penyimpanan Klien (`localStorage`)**: CBT player di `apps/web` hanya menyimpan ID jawaban terpilih siswa yang di-scope berdasarkan User ID dan Exam ID. Tidak ada kunci jawaban, rubrik, ataupun data sensitif yang tersimpan.
   - **Kanonisasi Status Ujian & Sesi (Single Source of Truth)**: Diterapkan PHP Enum (`ExamStatus` dan `ExamSessionStatus`), konstanta model Eloquent, serta `CHECK constraint` pada database PostgreSQL (`exams_status_check` dan `exam_sessions_status_check`).

2. **Tahap 2 — Perluasan Pengujian UI (Playwright Chromium Headless)**:
   - **Render & Autosave 6 Tipe Soal**: Terverifikasi dan terdokumentasi visual untuk Pilihan Ganda (PG), PG Kompleks (multi-select), Benar/Salah (BS), Menjodohkan (Matching), Isian Singkat, dan Uraian/Esai.
   - **Pengerjaan Penuh 20 Soal & Kalkulasi Nilai Otomatis**: 18 butir soal objektif dinilai otomatis oleh server pasca submit, sedangkan 2 butir soal uraian berstatus menunggu penilaian manual guru (`score = null`, `is_graded = false`).
   - **Ketahanan Jaringan (Offline Queue 5+ Soal)**: Menjawab 5 soal saat offline, menutup tab browser, lalu membuka kembali saat online terbukti pulih 100% tanpa duplikasi data.
   - **Anti-Cheat Monitoring**: Keluar fullscreen dan perpindahan tab/window blur tercatat di audit log dan memunculkan dialog peringatan integritas.
   - **Konkurensi Multi-Siswa**: Dua siswa (`siswa.lab.001` dan `siswa.lab.002`) mengerjakan ujian secara bersamaan dalam dua browser context terpisah tanpa ada percampuran data (*zero cross-talk*).
   - **Timeout Auto-Submit**: Server-side locking otomatis menyelesaikan sesi ketika batas waktu terlampaui.

3. **Status Test Suite & Kualitas Kode**:
   - **PHPUnit Test Suite**: **1191 tests lulus 100% hijau** (0 gagal, 7900 assertions).
   - **Laravel Pint**: **100% Passed (Zero formatting violation)**.
   - **TypeScript & ESLint `apps/web`**: **0 errors**.

## 3. AUDIT STORAGE KLIEN (`localStorage` & `IndexedDB`)

Pemeriksaan pada kode `apps/web/src/app/(portal)/portal/siswa/ujian/[id]/page.tsx`:
- **IndexedDB**: Tidak digunakan sama sekali oleh player CBT.
- **localStorage Keys**:
  - `cbt_pending_answers_${scope}_${examId}`: Menyimpan *map* ID butir soal terhadap pilihan/jawaban siswa lokal untuk kebutuhan buffer offline. Tidak memuat kunci jawaban.
  - `cbt_pending_answers_meta_${scope}_${examId}`: Menyimpan timestamp pengerjaan dan idempotency key.
  - `cbt_active_owner_${examId}`: Menyimpan user ID siswa aktif untuk mencegah percampuran state jika berganti akun di peramban yang sama.
  - `cbt_pending_violations_${scope}_${examId}`: Menyimpan antrean audit pelanggaran offline.
- **Pembersihan Otomatis**: Saat pengumpulan ujian berhasil (`finishSession`), fungsi `clearOfflineQueues()` membersihkan seluruh data di `localStorage`.

## 5. DAFTAR TEMUAN BUG & PERBAIKAN

### [BUG-CBT-03] Array Format Mismatch pada Penilaian Otomatis PG Kompleks
- **Severity**: 🟡 **MEDIUM (Scoring Calculation Bug)**
- **File**: `apps/api/app/Services/Cbt/ExamGradingService.php` (baris 470–485)
- **Deskripsi**:
  Sebelumnya `evaluateObjectiveAnswer` hanya memeriksa `$userAnswer['selected_option_ids']` atau `$userAnswer['option_ids']`. Jika klien mengirimkan array flat `['id-1', 'id-2']` (format list PHP/JSON biasa), `$chosenIds` menjadi array kosong sehingga skor PG kompleks selalu dihitung 0.
- **Perbaikan**:
  Menambahkan pengecekan `array_is_list($userAnswer)` untuk mendukung array flat ID maupun objek terbungkus `{selected_option_ids: [...]}`.

### [BUG-CBT-04] Jawaban Objektif Tidak Langsung Dinilai Otomatis saat Finish Session
- **Severity**: 🟡 **MEDIUM (Grading Pipeline Timing)**
- **File**: `apps/api/app/Services/Cbt/ExamSessionService.php` (baris 565–575)
- **Deskripsi**:
  Saat siswa menekan tombol submit (`finishSession`), sesi hanya ditandai `selesai` tanpa memicu penilaian butir objektif secara otomatis (hanya timeout lock yang memicunya). Akibatnya, `session->score` tetap `null` sampai pengawas/guru menekan tombol auto-grade.
- **Perbaikan**:
  Memanggil `gradeSessionObjectiveAnswers($session)` di dalam transaksi `finishSession`. Seluruh 18 butir objektif langsung dinilai dan total skor sesi diperbarui, sementara 2 butir uraian tetap berstatus `score = null` menunggu penilaian manual guru.

### [BUG-CBT-05] Variabel `$_SERVER` Tidak Direset pada Guard UatSeederTest
- **Severity**: 🟢 **LOW (Testing Environment Contamination)**
- **File**: `apps/api/tests/Feature/Auth/UatSeederTest.php`
- **Deskripsi**:
  Pengujian keamanan lingkungan staging seeder hanya mengubah `putenv()` dan `$_ENV`, sementara fungsi `env()` Laravel memprioritaskan `$_SERVER`. Hal ini menyebabkan assertion exception gagal saat dijalankan dalam test runner tertentu.
- **Perbaikan**:
  Menyinkronkan penulisan dan pembersihan `$_SERVER['UAT_SEED_ENABLED']` pada setup dan teardown test.
